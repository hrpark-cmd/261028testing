# Claude Code 프롬프트 모음

아래 프롬프트를 Claude Code에 **한 번에 하나씩** 붙여넣어 사용하세요.
모든 프롬프트에는 "Spark 무료 요금제 유지" 조건이 들어 있습니다.

---

## 0. MVP 사이트 생성 (이 저장소를 처음부터 만들 때 쓴 프롬프트)

```
기계공학과 교수 연구실 웹사이트를 MVP로 만들어줘.

[목적]
- 연구 자료와 수업 자료를 모아두고, 대학원생들과 연구 결과를 논의하는 사이트

[기술 조건]
- 빌드 도구 없는 순수 HTML/CSS/JavaScript(ES Module). GitHub에 올려 Netlify로 배포 (netlify.toml 포함)
- Firebase JS SDK는 gstatic CDN에서 불러오기
- Firebase Spark(무료) 요금제 기능만 사용: Firestore, Authentication(Google 로그인)
- Cloud Storage, Cloud Functions 등 Blaze가 필요한 기능은 쓰지 말 것. 파일은 외부 링크로 등록
- firebase-config.js 에 설정값 자리표시자를 두고, 설정 전에도 사이트가 깨지지 않게(예시 데이터 표시)

[페이지]
1. 홈: 연구실 소개, 각 메뉴로 가는 카드
2. 연구: 연구 자료 목록(제목, 연도, 요약, 링크). 누구나 열람, 관리자만 등록/삭제
3. 수업: 수업 자료 목록(제목, 학기, 요약, 링크). 누구나 열람, 관리자만 등록/삭제
4. 토론: 로그인 사용자만 글 목록/작성. 글 상세 페이지에서 댓글 작성/삭제

[권한]
- 관리자는 Firestore admins/{uid} 문서 존재 여부로 판단
- firestore.rules 파일로 위 권한을 강제. 본인 글/댓글만 수정·삭제(관리자는 전부 가능)

[기타]
- 한국어 UI, 모바일 대응, 다크 모드 지원
- 사용자 입력은 textContent로 출력해 XSS 방지
- README.md에 Netlify 배포, Firebase 연동, 관리자 지정 방법을 단계별로 한국어로 정리
```

## 1. 연구실 정보 채우기

```
사이트의 "OO 연구실", "OOO 교수" 자리표시자를 아래 정보로 바꿔줘.
- 연구실 이름: (예: 구조역학 연구실)
- 교수 이름/직함: 
- 연구 분야 키워드: 
- 연락처(이메일, 연구실 위치): 
홈 화면에 연구 분야 소개 섹션과 연락처 섹션도 추가해줘.
```

## 2. 학교 계정만 로그인 허용

```
토론 게시판을 우리 학교 Google 계정(@kmu.ac.kr)만 쓸 수 있게 해줘.
- 로그인 시 GoogleAuthProvider에 hd 파라미터 지정
- firestore.rules에서도 request.auth.token.email 이 @kmu.ac.kr 로 끝나는지 검사
- 다른 계정으로 로그인하면 안내 메시지 후 로그아웃
Spark 무료 요금제 기능만 사용해줘.
```

## 3. 구성원(대학원생) 승인제

```
관리자가 승인한 구성원만 토론 게시판을 쓰게 바꿔줘.
- 최초 로그인 시 users/{uid} 에 status: "pending" 저장
- 관리자 전용 "구성원 관리" 페이지(members.html)에서 승인/거절
- firestore.rules: posts/comments는 status가 "approved"인 사용자만 접근
Cloud Functions 없이 Spark 무료 요금제로만 구현해줘.
```

## 4. 게시판 기능 강화

```
토론 게시판에 다음 기능을 추가해줘 (Spark 무료 요금제 내에서).
- 카테고리(연구 토론 / 수업 질문 / 공지) 선택 및 필터
- 글 수정 기능(작성자 본인, 관리자)
- 공지 글은 관리자만 작성 가능하고 목록 상단에 고정
- 본문에 Markdown 지원(marked + DOMPurify CDN, XSS 방지)
- 수식 표시를 위해 KaTeX 지원 ($...$, $$...$$)
firestore.rules도 함께 수정해줘.
```

## 5. 연구 자료를 특정 게시글과 연결

```
연구 자료 카드마다 "이 연구에 대해 토론하기" 버튼을 추가해줘.
- 누르면 해당 연구 ID(researchId)가 연결된 게시글 목록/작성 화면으로 이동
- 연구 상세 페이지(research-detail.html?id=...)에서 연결된 토론 글을 함께 보여주기
필요한 Firestore 복합 인덱스가 있다면 README에 생성 방법을 적어줘.
```

## 6. 수업 자료 확장

```
수업 페이지를 과목별로 정리해줘.
- 과목(courses) 아래에 주차별 자료(courses/{id}/lectures) 서브컬렉션
- 각 주차: 주차 번호, 제목, 강의자료 링크, 과제 링크
- 관리자는 과목 페이지에서 주차 자료를 추가/삭제
파일 업로드는 Cloud Storage 대신 Google Drive 링크로 해줘 (Spark 요금제).
```

## 7. 연구실 구성원 / 논문 실적 페이지

```
people.html(구성원 소개)과 publications.html(논문 실적) 페이지를 추가해줘.
- 구성원: 이름, 과정(석사/박사/박사후), 연구 주제, 사진 URL, 이메일
- 논문: 저자, 제목, 저널, 연도, DOI. 연도별 그룹 표시, 검색 필터
- 둘 다 누구나 열람, 관리자만 Firestore에서 등록/수정/삭제
```

## 8. 마무리 점검

```
현재 사이트 전체를 점검해줘.
- firestore.rules 가 모든 컬렉션 접근을 의도대로 막는지 검토
- 로그인/비로그인/관리자 상태별로 각 페이지 동작 확인
- 모바일 화면 레이아웃 확인
- Spark 요금제를 벗어나는 기능이 없는지 확인
문제가 있으면 고치고 무엇을 바꿨는지 정리해줘.
```
